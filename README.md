# Student_TaskManager
A modern Student Task Manager web app with authentication, task management, deadlines, priorities, and dark mode support using HTML, CSS, and JavaScript.
<br>
Features:
- Authentication: Sign up, login, logout with email and password. Password strength indicator.
- Task Management: Add, edit, delete, and mark tasks as complete. Tasks are stored in localStorage.
- Task List: Display all tasks with title, description, deadline, priority, and completion status.
- Filters & Sorting: Filter tasks by priority and completion status. Sort tasks by deadline or priority.
- Dark Mode: Toggle between light and dark mode for better viewing experience.
- UI/UX: Modern, responsive design with smooth animations and transitions.
- Data Persistence: All tasks and user data are securely stored in the browser's localStorage.
- Validation: Real-time form validation for secure authentication and task creation.
